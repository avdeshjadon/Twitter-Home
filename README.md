# Twitter Home Page Clone

A responsive clone of the Twitter (X) home page built with pure HTML and CSS.

- **Live Demo**: [Experience the Clone](https://avdeshjadon.github.io/Twitter-Home/)
- **Repository**: [GitHub Repo](https://github.com/avdeshjadon/Twitter-Home)

## Features

- **Responsive Design**: Adapts across desktop, tablet, and mobile layouts.
- **Pure HTML & CSS**: No JavaScript dependencies, lightweight and fast.
- **Authentic UI**: Complete sidebar navigation, feed with tweet cards, and trending section.
- **Dark Theme**: Matches Twitter's native dark interface.

## Tech Stack

- HTML5
- CSS3 (Flexbox & Media Queries)
- GitHub Pages

## Quick Start

1. Clone the repository:
```bash
git clone https://github.com/avdeshjadon/Twitter-Home.git
cd Twitter-Home
```

2. Open `index.html` in any browser.
